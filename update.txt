ArenaLab update v1
version: 1.1.2
kind: hotfix
note: Fonts: reopening a .fntpck now remembers which typeface, size and effects it was made with, so touching any control redraws it with YOUR font instead of the default one. A .fntpck stores bitmaps and does not record this, so it is kept beside the app, keyed by the file's contents.
note: Fonts: for a font made on another machine there is nothing to remember, so the app now asks before redrawing it instead of silently changing the typeface.
note: Matchups: the preview now steps lines apart the way the game does. It used to floor the step at the letter height, so lines that pile on top of each other in game looked fine here.
note: Matchups: the panel warns when the lines will overlap in game, and says what line spacing they need.
note: Matchups: saving now says that the game reads the baked arena, not the file you just wrote -- installing it again is a separate step.
