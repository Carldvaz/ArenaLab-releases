ArenaLab update v1
version: 1.6.0
note: ArenaDef: the AudienceLab button on the crowd part now opens AudienceLab in the downloaded app. It was looking for it in a temporary folder instead of next to ArenaLab.exe, so it always said it could not find it. Put AudienceLab.exe in the same folder as ArenaLab.exe (or in an AudienceLab folder next to it) and the button opens it, already pointing at your base files.
note: New emblem: ArenaLab now matches the other Lab apps (AudienceLab, JigLab, UpscaleLab). It shows the whole venue from above -- stage, ramp, ring and stands -- and stays readable at taskbar size.
note: Opened from ModHub, ArenaLab takes the game files and the game folder that ModHub knows, so there is nothing to set up on the first launch. It follows ModHub until you pick a different base folder inside ArenaLab; a folder you already had stays.
note: Fonts: "Make a .slug from a typeface…" no longer loops asking where to save it. When no game .slug is found to use as a base, it asks once for your game fonts folder, remembers where you chose to save, and if that folder has no usable base it names the game fonts that work and stops.
note: Settings: the Game fonts folder now works at any level you pick -- the folder above UI, UI itself or UI\Assets\Slug. Picking UI\Assets\Slug used to count the fonts without finding any of them.
note: ShowAssets: each text is previewed with its own font when that font is in your folders -- a .slug with its letter shapes, a .fntpck with its own sheet -- so a matchup that mixes fonts shows all of them. The font picked above is now only the stand-in for texts whose font you do not have.
note: ShowAssets: the unidentified text field in slot 029 (unk_30 in other tools, used by some creators as a secondary scale) can be edited in the text panel. The preview does not draw it yet: check the result in game.
note: ShowAssets: fixed matchups that crashed the game after being saved. When a matchup ported from 2K25 had to be rebuilt on save, its effects block was written with a broken pointer. Saving now checks for it before writing.
note: ShowAssets: dragging the handles of an image or shape now changes its box, not its zoom. With a different zoom on each axis the game draws a piece differently from box x zoom; pieces that already carry such a zoom show a warning and a "Move the zoom into the box" button, and the preview draws them the way the game does.
note: ShowAssets: images have box fields and a "Real size of the image" button that sets the box to the size of the .dds.
note: Nameplates and locators: the FontRoot's own font, which some packs carry besides the texts' font, can be changed like any other resource, and "Use this font in the file" includes it.
note: Nameplates and locators: the animation timeline runs at the frame rate of the video on screen instead of always 30 fps, so the ruler, the needles and playback are in real seconds.
note: Movies: new "Separate: own set". When several arenas share a graphics set, it gives this arena its own copy -- same videos, owned by this arena -- so you can change its videos without touching the others. It asks before doing it to an arena that ships with the game.
note: ArenaData: the "playable" fix also sets the two flags that the game's menu arenas carry next to the menu flag, so an arena missing them is flagged.
note: Arena packs: Export arena pack puts one or more arenas in a single .arenalab, each with its Tribute .arenaprofile and, if you want, its BoothLab booths, its AudienceLab crowd and its .cak (inside the pack or sent separately). Each arena is recognised by its ArenaDef, not its ID, so it fits on another PC whatever ID it gets there. An arena's own props go with it automatically (and the two extra pieces of custom steel steps). Open arena pack shows what it brings and what you already have, and saves the Tribute files for you.
note: Prop ID guide for creators: when you export a pack, ArenaLab looks your prop numbers up in a shared guide of ranges set aside by each creator, and suggests another number if one falls in someone else's range. It is a guide, not a rule: no number is locked. Open it from Export arena pack to look up a number or set aside your own range.
note: Arena packs: when a pack brings a crowd of its own, Open arena pack tells you if it is already in your BakeMe's crowd list and can add it for you (Add the crowd). Without that entry, the arenas that use it crash when they load.
note: Arena packs: What it needs... lists what a pack needs on this PC so its arenas don't crash when they load (its .cak, its crowd, its props, each arena and the bake), step by step, with what is already done and where each step is done.
note: Arena packs and Tribute: the ArenaLab plugin for Tribute installs .arenalab packs by itself, without ArenaLab: it copies the .cak to mods, adds the crowd, and has Tribute create the props and arenas in one batch (it bakes only if you tick it). A full copy of your BakeMe is made first, and a check compares what Tribute reports with your BakeMe so only matching settings are written. With ArenaLab opened from the plugin, Install everything hands the pack to the plugin. ArenaLab, AudienceLab and the plugin write the crowd list the same way, so using them on the same BakeMe never duplicates or breaks it.
note: Add with Tribute replaces Save changes: it saves the files in the arena folder (ArenaDef, Preload, Ring...) and hands Tribute, through its ArenaLab plugin, what goes in the BakeMe: new arenas are created, edited ones updated (their settings, name, matchup and videos) and deleted ones removed. If Tribute isn't open, ArenaLab offers to open it and carries on as soon as you open the plugin (Power Tools > Plugins > ArenaLab). The list is simpler: Import/Export settings, Import/Export profile and Save Master Files (JSON) are gone; arena packs take their place, now in every build.
note: Export arena pack: each arena's .cak list now shows every .cak in your mods folder, with the one whose name looks most like the arena (or the arena's folder) already picked. Change it if it guessed wrong; Add a .cak... is still there for one that lives somewhere else.
note: Export arena pack: each arena has "Has custom props?". Tick it and pick its props from the custom props in your AssetMap (the ones that don't come with the game; a ladder brings its 2 pieces). With the arena's folder open, the props its PropsSet asks for come already ticked; without it you tick them by hand, so the folder no longer has to be open. If its PropsSet asks for a prop you left out, the pack is still written, with a warning. And an arena whose ArenaDef isn't in your open folders is found by its name when the name gives it away (checked against the ArenaDef's hash).
note: Settings: a Game fonts folder that holds a whole game extraction no longer hides your own files. Its files only fill gaps now; before, they won over your base folder and your arena folder, so ArenaLab could read the game's PropsData_AssetMap, AudienceDefs or a PropsSet instead of yours.
note: Export arena pack: a booth, crowd or .cak in the lists that no ticked arena uses now says so ("no arena uses it: it won't go in the pack"), and the export tells you what was left out; before, it was dropped without a word. A booth that names no arena (saved by BoothLab before you assigned it) is suggested for the arenas no other booth names.
note: There is no separate free build any more: whoever has it gets the public build with this update, which does everything the free one did and more.
