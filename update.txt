ArenaLab update v1
version: 1.2.0
note: ShowAssets: dragging a text on the canvas now changes its font size and box instead of its zoom. It looks exactly the same while dragging, but the file is left the way the game builds text -- a text with its own zoom is something the game almost never does (1 in 1,864), and there the preview and the game can break lines differently.
note: ShowAssets: what used to be Scale X / Scale Y is now called Zoom X / Zoom Y, and on a text it can only be changed from the panel.
note: ShowAssets: a text that already carries its own zoom gets a warning, with a button to move it into font size and box -- for that text, or for every text in the project at once, in a single undo step. The letters and the box come out exactly the same.
note: Updates: pressing Update now closes ArenaLab and opens a small window that downloads the new version with a progress bar, checks it against the signed manifest, installs it and opens it. If anything goes wrong it says so and offers to open the version you had -- you are never left without the app, and closing that window halfway through brings your old version back too.
